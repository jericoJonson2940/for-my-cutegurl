MUSIC:
I did not receive the 4:14 music file yet. Put your song in this folder and rename it:
    music.mp3

Then open index.html in a browser. On the first screen, tap "Tap to open 💗".
That tap starts the animation and music together (subject to the browser's audio rules).

ADDING MORE IMAGES:
Put new images inside assets/ and add another slide object in script.js.
The slideshow is designed so the music can keep playing continuously while images/text transition.

NOTE:
For a phone, Chrome may not allow audio to begin until the user taps something. The "Tap to open" button is intentional so the first tap is the user gesture that starts the music.
